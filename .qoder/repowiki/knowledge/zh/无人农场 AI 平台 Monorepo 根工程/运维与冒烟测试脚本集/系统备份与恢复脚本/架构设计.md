模块由两个独立且对称的 ESM 脚本组成，职责严格分离：
- `scripts/backup-system.mjs`：解析命令行参数（`--db-only` / `--code-only` / `--include-secrets` / `--keep` / `--dir` / `--tag` / `--list`），依次执行三类备份——代码优先 `git archive`（回退到 `tar` 排除 `node_modules/.git/.tmp/backups/restore`）、配置打包 `.env.example`（可选附带 `.env` 与 `ed25519-private.pem`）、数据库优先本机 `pg_dump`（回退到 `docker compose exec postgres pg_dump`）；产物写入 `<BACKUP_DIR>/<YYYYMMDD-HHMMSS>/` 目录并生成 `manifest.json`，最后按时间排序裁剪旧备份。
- `scripts/restore-system.mjs`：读取同一 `manifest.json`，通过 `tar -xzf` 解压代码包到 `--target`（默认 `./restore`），并通过 `pg_restore` 或 `docker compose exec postgres pg_restore` 从 stdin 流式恢复数据库；支持 `--only code|db` 选择性恢复。
两脚本共享相同的约定：备份产物以 `code-*` / `config-*` / `db-*` 命名前缀区分，依赖外部工具而非 Node 库，通过 `commandAvailable` 探测可用性后降级；`manifest.json` 是唯一的契约文件，记录每个 part 的 `name`、`path`、`bytes`、`sha256`，供恢复脚本反向查找。
