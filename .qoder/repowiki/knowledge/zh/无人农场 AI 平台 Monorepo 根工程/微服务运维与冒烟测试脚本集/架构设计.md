脚本以 `service-registry.mjs` 为单一事实源，集中声明 15 个子服务的 `[name, port, entry]` 三元组（指向 `apps/*/dist/main.js`），并通过 `getServices()` 暴露，允许通过 `AGRI_<NAME>_PORT` 环境变量覆盖端口。

按职责分为四类：
- 生命周期类：`start-services.mjs` 使用 `child_process.spawn(process.execPath, [entry])` 并行拉起全部服务，gateway 额外注入其他服务的 `*_SERVICE_URL`，并通过 SIGINT/SIGTERM 钩子统一回收；`clean.mjs` 递归删除 `packages/*` 与 `apps/*` 下的 `dist` 与 `tsconfig.tsbuildinfo`。
- 健康检查类：`health-check.mjs` 并发轮询各服务 `/health`；`health-infra.mjs` 用 `net.createConnection` 探测 Postgres TCP，用 HTTP 探测 MinIO `/minio/health/live`。
- 冒烟测试类：`smoke-gateway.mjs` / `smoke-services.mjs` / `smoke-decision-telemetry.mjs` / `smoke-authz.mjs` / `smoke-consumers.mjs` / `smoke-events.mjs` / `smoke-identity.mjs` / `smoke-message-preferences.mjs` / `smoke-weather.mjs` / `smoke-zones-navigation.mjs` 各自维护最小服务子集，启动后轮询 `/health` 就绪，再按业务链路调用网关 API 断言状态码与响应体。
- 运维类：`init-minio.mjs` / `migrate-postgres.mjs` 分别初始化对象存储与数据库迁移。

依赖方向单向：所有脚本 → `service-registry.mjs`；脚本之间无相互 import，仅共享同一仓库根目录结构。
