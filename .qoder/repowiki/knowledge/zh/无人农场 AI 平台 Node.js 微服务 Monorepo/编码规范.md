- 共享能力以 @agri/* 命名空间发布为独立 TypeScript 包，微服务通过 package.json 依赖引入而非相对路径引用。
- 跨包类型依赖通过根 tsconfig.json 的 project references 显式声明，禁止隐式发现。
- 测试代码放在 packages/**/test 或 apps/**/test 下，使用 .spec.ts 后缀并由 Vitest 自动发现。
- 数据库变更采用按编号递增的 SQL 迁移文件，由 scripts/migrate-postgres.mjs 顺序执行。
- 本地开发环境通过 Docker Compose 启动 PostGIS 与 MinIO，scripts/* 脚本负责健康检查与服务编排。
