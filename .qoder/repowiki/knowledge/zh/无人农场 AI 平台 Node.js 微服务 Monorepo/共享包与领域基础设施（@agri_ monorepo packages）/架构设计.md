本模块是 @agri/* monorepo 的共享层，所有包均为 `private: true` 的 npm 包，通过 `pnpm workspace:*` 相互引用，构建统一使用 `tsc -b` 增量编译。

- 依赖方向自底向上分层：
  - 基础层：`@agri/tsconfig`（仅导出 base/library/nest/vue/strict 五个 tsconfig 片段）、`@agri/shared`（异常基类、时间、单位换算、分页、标识生成等纯工具，无运行时依赖）。
  - 契约层：`@agri/contracts`（响应信封、领域事件、错误码、DTO、枚举），仅依赖 zod，作为跨包类型契约中心。
  - 能力层：`@agri/config`（环境变量校验 + 启动期加载，依赖 NestJS + zod）、`@agri/db`（客户端生命周期、事务、分库路由、分页、软删除）、`@agri/mq`（发布订阅、本地消息表、重试死信、幂等）、`@agri/observability`（结构化日志、链路追踪、指标采集）。
  - 领域层：`@agri/plot-core`（六段式地块编码、校验位算法、网格换算、坐标系转换）。
  - 测试层：`@agri/testing`（测试数据库、内存事件总线、可控时钟、模块构造器、数据夹具），依赖 contracts/db/plot-core/shared/Nest testing。

- 每个包均遵循同一发布约定：`main`/`types` 指向 `dist/index.js`，并通过 `exports` 字段暴露 ESM 入口；多入口包（如 contracts）在 exports 中显式声明子路径。
