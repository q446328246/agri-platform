- Pinia store 采用 Composition API 风格的 `defineStore('name', () => {...})` 写法，state 用 `ref` 声明，方法直接返回对象而非 methods 字段。
- 路由按业务子系统拆分到 `router/modules/*.routes.js`，主路由文件仅做合并与守卫，页面组件一律使用 `() => import(...)` 按需懒加载。
- 所有 HTTP 请求统一走 `src/api/http.js` 导出的 axios 实例，禁止在业务文件中直接 new Axios，后端响应体约定为 `{code, data, message}` 且 200 才视为成功。
- 认证态通过 `useAuthStore().token` 判断，401 响应由拦截器统一清除 token 并跳转 `/login`，路由守卫依据 `meta.public` 标记放行公开页面。
- ECharts 图表通过 `components/charts/BaseChart.vue` 基类 + `BarChart/LineChart/PieChart` 子类复用，图表选项集中在 `utils/ChartOptions.js` 与 `constants/chart.constants.js`。
- ArcGIS 地图初始化封装在 `composables/useEsriMap.js`，业务视图通过该 composable 获取地图实例，避免在多个 View 中重复调用 esri-loader。
