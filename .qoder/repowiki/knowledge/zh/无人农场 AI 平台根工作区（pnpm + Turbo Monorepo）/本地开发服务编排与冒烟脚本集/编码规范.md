- 服务元数据集中在 `service-registry.mjs` 的 defaults 数组中维护，其他脚本一律通过 `getServices()` 读取而非硬编码服务列表。
- 启动子进程统一使用 `spawn(process.execPath, [entry], { cwd: root, env: {...}, stdio: ['ignore','pipe','pipe'], windowsHide: true })`，并将 stdout/stderr 带 `[name]` 前缀转发到父进程。
- 对外部依赖的健康检查采用 try/catch + `process.exitCode = 1` 的模式，失败时保留非零退出码供 CI 消费。
- 脚本内路径解析统一通过 `path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..')` 获取仓库根目录，避免相对路径歧义。
