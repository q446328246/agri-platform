脚本以 `service-registry.mjs` 为单一事实源：集中声明所有业务服务（auth/plot/iot/telemetry/weather/decision/operation/control/video/finance/trace/message/file/platform/gateway）的名称、默认端口与 `apps/*/dist/main.js` 入口，并通过 `getServices()` 暴露可被其他脚本复用的服务清单。

- 启动类：`start-services.mjs` 通过 `child_process.spawn` 并行拉起所有服务，对 gateway 注入 `{SERVICE}_URL` 环境变量；`smoke-services.mjs` 在此基础上额外分配隔离端口段（3201+），等待 `/health` 就绪后统一退出。
- 健康检查类：`health-check.mjs` 仅查询应用 `/health`；`health-infra.mjs` 用 `net` TCP 探测 Postgres + HTTP 探测 MinIO。
- 运维工具：`clean.mjs` 递归删除 `packages/*` 与 `apps/*` 下的 `dist` 与 `tsconfig.tsbuildinfo`；`init-minio.mjs`、`migrate-postgres.mjs` 分别初始化 MinIO 与执行数据库迁移。
- 冒烟用例：`smoke-gateway.mjs`、`smoke-decision-telemetry.mjs` 针对特定业务路径做端到端验证。

依赖方向单向指向 `service-registry.mjs`，脚本之间不互相 import，全部通过命令行独立调用。
