- 数据库迁移文件采用数字前缀命名（如 `001_...sql`、`002_...sql`），按序号递增表达版本演进顺序。
- 表主键统一使用 `TEXT` 类型作为 ID，时间字段统一使用 `TIMESTAMPTZ`，逻辑删除字段命名为 `deleted_at`。
- 查询热点列建立带 `DESC` 排序的复合索引（如 `(tenant_id, created_at DESC)`、`(plot_code, created_at DESC)`），并按业务域前缀命名索引（`idx_<table>_<col>_<sort>`）。
- 需要幂等性的 DDL 语句统一使用 `CREATE TABLE IF NOT EXISTS` / `CREATE EXTENSION IF NOT EXISTS` 形式。
