- 组件与页面统一使用 Vue 3 `<script setup>` 语法，避免 Options API。
- 路由采用异步 `() => import(...)` 懒加载，并按业务子系统拆分为独立路由模块文件（`modules/*.routes.js`）后在 `index.js` 中展开合并。
- 所有 HTTP 请求经 `src/api/http.js` 的 Axios 实例发起，拦截器自动注入 `Authorization: Bearer <token>` 并统一解包 `{code,data,message}` 响应体。
- 认证状态集中在 `auth.store.js`（Pinia），并通过 `useAuthStore()` 在拦截器、路由守卫与组件中共享，token 同时保存在内存 ref 与 `localStorage` 中以支持刷新恢复。
- 样式统一使用 SCSS，并通过 Vite 的 `additionalData` 全局注入 `@styles/variables.scss`，组件内以 BEM 风格命名类名（如 `.main-layout__topnav`）。
- 业务子系统在 `views/<subsystem>/` 下按功能再分子目录（如 `growth/curve`、`weed/spray-prescription`），每个子页面为单一 `.vue` 文件。
