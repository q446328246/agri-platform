模块采用典型的 Vue3 单页应用分层结构：
- 入口与构建：`src/main.js` 创建 Vue 实例并挂载 Pinia、Router；`vite.config.js` 通过 `unplugin-vue-components` 自动注册 Element Plus 组件，使用 `@` 别名指向 `src`，SCSS 全局注入 `variables.scss`，开发代理 `/api` 到 `localhost:8080`。
- 路由层：`src/router/index.js` 以 Hash 模式运行（适配 Tomcat 部署），集中注册登录页、主布局下的公共页面以及 8 个业务子系统的懒加载路由（`farm/seedling/weed/pod/growth/lodging/maturity/yield`），并通过 `meta.public` 配合 `beforeEach` 实现登录鉴权。
- 状态管理：`src/stores/` 下按领域拆分 Pinia store（auth/dashboard/map/app），`auth.store.js` 将 token 持久化到 `localStorage`（key=`ag_token`），并提供 `hasPermission`/`hasRole` 权限判断。
- API 层：`src/api/http.js` 封装 Axios 实例，统一附加 Bearer Token、处理 `{code,data,message}` 响应结构与 401 跳转；各业务 API 文件（`auth.api.js`、`dashboard.api.js`）仅暴露函数调用。
- 视图与布局：`src/layouts/MainLayout.vue` 组合 TopNav/Sidebar 与 `<router-view>`；`src/views/` 按业务子系统划分目录，每个子系统含一个容器 View 和若干子页面。
- 可复用能力：`src/components/` 提供图表（ECharts 封装）、地图（ESRI ArcGIS via `esri-loader`）、数据卡片等通用组件；`src/composables/` 暴露 `useAuth`、`useEcharts`、`useEsriMap` 等组合式逻辑；`src/constants/` 集中配置常量；`src/styles/` 通过 SCSS 变量与 mixin 统一主题。
- 依赖方向：views → components/composables → stores/api → router；stores 不反向依赖视图，API 不直接操作 DOM。
