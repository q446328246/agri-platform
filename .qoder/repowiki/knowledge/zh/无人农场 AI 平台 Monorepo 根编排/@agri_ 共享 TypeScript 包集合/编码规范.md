- 每个包在 package.json 中同时声明 `main`、`types` 与 `exports.import`，保证 CommonJS 与 ESM 双端消费一致。
- 包间依赖一律通过 `workspace:*` 引用，禁止硬编码版本号，确保 monorepo 内版本同步。
- 对外暴露的类型与运行时 API 通过 `exports` 字段显式声明，新增子模块需在 exports 中注册对应路径。
- 构建脚本统一为 `tsc -b`，利用 TypeScript 项目引用实现跨包增量编译。
- 所有包标记 `private: true` 且 `type: module`，不直接发布到 npm registry。
