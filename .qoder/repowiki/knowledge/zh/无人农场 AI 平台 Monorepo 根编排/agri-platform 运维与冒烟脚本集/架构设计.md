所有脚本以 `service-registry.mjs` 为单一事实源，集中声明子服务的 `[name, port, entry]` 三元组并通过 `getServices()` 暴露；脚本之间无相互 import，仅共享仓库根目录结构与同一份服务清单。按职责分为四类：`start-services.mjs` 并行拉起全部服务并注入 `*_SERVICE_URL`，`clean.mjs` 清理构建产物；`health-check.mjs`/`health-infra.mjs` 并发探测 HTTP `/health` 与 Postgres TCP/MinIO 端点；十余个 `smoke-*.mjs` 各自维护最小服务子集，轮询就绪后按业务链路调用网关 API 断言响应。依赖方向单向：脚本 → service-registry，脚本 ↔ 脚本 无耦合。
