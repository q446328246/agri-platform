单页应用，入口为 `src/main.js`，通过 `createApp` 挂载 Pinia、Router 和全局样式。
- 路由层：`src/router/index.js` 使用 Hash 模式（适配 Tomcat 部署），集中注册登录页与主布局下的子路由；各业务子系统路由拆分到 `router/modules/` 下按模块懒加载。
- 状态管理：`src/stores/` 以 Pinia Composition API 风格定义 store（auth、app、dashboard、map），token 持久化到 `localStorage`。
- API 层：`src/api/http.js` 封装 Axios 实例，统一 baseURL `/api`、Bearer Token 注入、401 跳转及 `{code,data,message}` 协议解包；具体接口按领域拆分为 `auth.api.js`、`dashboard.api.js` 等。
- 视图层：`src/views/` 按业务域（farm、seedling、weed、pod、growth、lodging、maturity、yield、dashboard、system）组织，每个域含一个容器 View 与若干子页面；通用 UI 组件下沉至 `src/components/`（charts、data-card、map、common）。
- 地图能力：通过 `esri-loader` 在 `composables/useEsriMap.js` 中封装 ArcGIS 地图初始化，`mapAPI/MapApi.js` 暴露地图操作函数，配合 `stores/map.store.js` 共享地图实例。
- 构建配置：`vite.config.js` 启用 `unplugin-vue-components` 自动注册 Element Plus 组件，SCSS 全局注入变量，开发代理将 `/api` 转发至 `localhost:8080`，生产输出目录由 `VITE_PUBLIC_PATH` 环境变量控制。
- 部署形态：`public/WEB-INF/web.xml` 表明项目可打包后直接部署到 Tomcat，同时支持独立静态站点模式。
